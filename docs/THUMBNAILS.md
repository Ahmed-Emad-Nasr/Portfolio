# الـ thumbnails — اتعملت

## المشكلة

`getThumbnail()` بيحوّل `1.webp` لـ `1-thumb.webp`، وكل كومبوننت بيعرض
صورة بيمرّ عليها. **ولا صورة واحدة في مكتبة الـ cases كان ليها نسخة
مصغّرة — صفر من 530.**

الكومبوننتس بترجع للصورة الكاملة لما الـ thumb مش موجود، فمحدش لاحظ:
الصفحة شكلها سليم. بس المتصفح كان بيحمّل الصور الكاملة كلها.

## الحل

مكانش لازم تدوّر على سكربت الـ Python. **`sharp` متثبّت عندك أصلاً** في
الـ devDependencies (Next بيستخدمه)، فكتبت `scripts/generate-thumbs.mjs`
وشغّلته على المجلد اللي بعتهولي.

```bash
npm run thumbs             # يولّد الناقص بس
npm run thumbs -- --dry    # يقولك هيعمل إيه من غير ما يكتب
npm run thumbs -- --force  # يعيد توليد كل حاجة
```

## ملف `thumbnails.zip`

فيه الـ 530 صورة مولّدة بالفعل، بنفس هيكل المجلدات. فك الضغط جوه
`public/` وهي هتقع في مكانها الصح على طول:

```bash
# من جذر المشروع
unzip thumbnails.zip -d public/
npm run check:links     # للتأكيد
```

**العرض:** 640 بكسل، جودة 72. لو لقيت أي صورة مصغّرة باينة مهزوزة، زوّد
`THUMB_WIDTH` في السكربت وشغّله بـ `--force`.

## وفي الطريق، السكربت لقى تلات مشاكل تانية

### 1. ثغرة في سكربت الفحص نفسه — اتصلحت

`check-assets` كان بيفحص **المجلد** بس لما المسار متولّد بـ template
literal:

```ts
Array.from({ length: 24 }, (_, i) => `…/Screenshot (${343 + i}).webp`)
```

المجلد موجود → عدّى الفحص. بس الشكل ده بيفترض إن الأرقام متتابعة من غير
فجوات.

دلوقتي السكربت **بيفكّ الحلقة ويفحص كل ملف بالاسم**. عدد المراجع اللي
بيتفحص قفز من **188 لـ 624**.

### 2. فجوتين في تسلسل صور WannaCry

```
الموجود: 343 344 345 346 347 348 ▢ 350 351 352 ▢ 354 … 366
الناقص:                          349            353
```

الكود كان بيطلب 343–366 كاملة، فصورتين في كل عرض للـ case ده كانوا
مكسورين.

الأرقام اتكتبت صريحة بدل التسلسل: أطول شوية، بس بتوصف الموجود فعلاً بدل
ما تفترض. لو ضفت الصورتين، رجّع `Array.from`.

### 3. Simple CTF بامتدادين مختلفين 🔴

```ts
سطر  85:  Screenshot (${49 + i}).webp     ← صح
سطر 797:  Screenshot (${49 + i}).png      ← الملفات مش .png
```

نفس غلطة Serpent Stealer بالظبط: الـ case معرّف في مكانين واتنينهم
اختلفوا. شبكة الأدلة في صفحة الـ case كانت بتعرض **11 صورة مكسورة**.
