المقال ده **مسودة** (`draft: true`)، يعني بيظهر وانت شغال بـ `npm run dev` بس،
ومش بيتنشر على الموقع. انسخه وغيّر الاسم والبيانات اللي فوق، وخلّي
`draft: false` — كده عندك مقال جديد.

## الاتجاه واللغة

لما تكتب `lang: ar` في أول الملف، الصفحة كلها بتبقى من اليمين للشمال:
العناوين، القوائم، وعمود "محتوى المقال". الخط بيبقى IBM Plex Sans Arabic.

## الكود

الكود بيفضل من الشمال لليمين، وليه زرار نسخ:

```powershell
Get-WinEvent -FilterHashtable @{ LogName = 'Security'; Id = 4625 } -MaxEvents 20
```
