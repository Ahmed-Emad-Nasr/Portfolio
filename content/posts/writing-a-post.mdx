## Front matter

The block between the `---` lines at the top describes the post. The file name
becomes the URL: `content/posts/wazuh-rule-tuning.mdx` is published at
`/blog/wazuh-rule-tuning`.

| Field | Required | What it does |
| --- | --- | --- |
| `title` | yes | The headline, the card title and the share title |
| `description` | yes | One sentence for the card, search results and link previews |
| `date` | yes | Publication date, `YYYY-MM-DD` |
| `tags` | no | Each tag gets a page at `/blog/tag/<tag>` |
| `lang` | no | `en` (default) or `ar` — Arabic posts are laid out right-to-left |
| `series`, `seriesPart` | no | Posts in the same series link to each other in order |
| `cover` | no | An image under `public/`, also used as the share image |
| `draft` | no | `true` keeps the post out of the build |

## Code

Fenced code is highlighted at build time and gets a copy button. Name the
language after the opening fence:

```bash
sudo /var/ossec/bin/wazuh-logtest
```

```xml
<rule id="100100" level="10">
  <if_sid>5710</if_sid>
  <match>Failed password</match>
  <description>SSH brute force from $(srcip)</description>
  <mitre><id>T1110</id></mitre>
</rule>
```

```kql
SecurityEvent
| where EventID == 4625
| summarize attempts = count() by TargetAccount, IpAddress, bin(TimeGenerated, 5m)
| where attempts > 10
```

Supported out of the box: bash, PowerShell, cmd, Python, JS/TS, JSON, YAML,
XML, HTML, SQL, KQL, SPL (Splunk), Sigma (as YAML), YARA, INI, TOML, diff,
HTTP, Dockerfile, nginx, logs, C, Go, asm and regex. Anything else renders as
plain text.

### Inline code and keys

Inline code looks like `Get-WinEvent -LogName Security`. Keys use the `Kbd`
tag: press <Kbd>Ctrl</Kbd> + <Kbd>K</Kbd> to open the command palette.
