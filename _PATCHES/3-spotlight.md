# ٣ — بقعة الضوء (اختياري)

القواعد بتاعة `Spotlight.tsx`. **ضيف في آخر `app/globals.css`.**

```css
/*--------- 18. بقعة الضوء ---------*/
/*
 * بتشتغل مع <Spotlight> بس. المكوّن بيكتب --spot-x و --spot-y وبيحط
 * data-spot="on" على الكارت اللي تحت الماوس.
 *
 * التدرّج على ::after ونفس الـ ::after بتاع اللمعة في قسم ١٦ — عشان
 * كده اللمعة بتتلغي هنا. الاتنين مايشتغلوش مع بعض: لمعة بتعدّي وبقعة
 * بتتبع الماوس في نفس اللحظة بتبقى زحمة.
 */
[data-fx="card"][data-spot="on"]::after {
  background: radial-gradient(
    circle 180px at var(--spot-x, 50%) var(--spot-y, 50%),
    rgba(var(--accent-color-rgb), 0.10),
    transparent 70%
  );
  /* اللمعة بتتلغي — التدرّج ده مكانها */
  transform: none;
  transition: opacity 200ms linear;
  opacity: 1;
}

[data-fx="card"]::after { opacity: 1; }
[data-fx="card"]:not([data-spot="on"])::after { opacity: 1; }
```

---

## التكلفة، بصراحة

ده **المكوّن الوحيد في الحزمة اللي بيكلّف حاجة فعلاً**. باقي التفاعلات
CSS خالص.

`radial-gradient` بموضع متغيّر معناه **إعادة رسم الكارت في كل فريم**
الماوس بيتحرك فيه. مش layout، ومش الشاشة كلها — كارت واحد. على ديسكتوب
مش هتحسه.

عشان كده المكوّن بيخرج بدري على:
* أي جهاز لمسي
* أي `tier` مش `"high"` — يعني كل التليفونات والتابلت وأي لابتوب ضعيف
* `prefers-reduced-motion`

يعني اللي بيدفع التكلفة دي هو بس الجهاز اللي مش هيحسها.

## اللي عملته عشان يبقى رخيص

**listener واحد على الحاوية** مش على كل كارت. شبكة ١٢ كارت = listener
واحد.

**rAF throttle.** `pointermove` بيضرب لحد ١٢٠ مرة في الثانية على شاشة
120Hz. من غير الـ throttle كنا هنكتب على الـ DOM أكتر من عدد الفريمات
اللي بتترسم — شغل بيتلغي قبل ما يبان.

**متغيّرين CSS بس.** مفيش حساب تخطيط في الجافاسكريبت، مفيش قراءة
خصائص.

**`passive: true`.** بيقول للمتصفح إن الـ handler مش هيعمل
`preventDefault`، فمش محتاج يستناه قبل ما يكمّل الـ scroll.

---

## لو مش عايزه

متضفهوش. قسم ١٦ (اللمعة اللي بتعدّي) بيدّي إحساس قريب بصفر تكلفة —
تدرّج ثابت بيتحرك بـ `transform` بدل تدرّج متغيّر بيتعاد رسمه.

الفرق إن اللمعة حركة واحدة بتعدّي، والبقعة بتفضل تتبع الماوس. التانية
أحلى، الأولانية مجانية.
